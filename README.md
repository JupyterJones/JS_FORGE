## 🕹️ The Experience & Features

### 1. The LogicForge Pedagogy: "Watch Demo ➔ Play & Learn to Advance"
* **📺 WATCH DEMO**: Click this button in any sector to watch an optimal JavaScript solution run automatically.
* **Live Step Tracing**: Watch the **code lines highlight in real time** in the editor as the Cyber Rover executes each instruction!
* **Learn to Advance**: To unlock the next sector, you write or modify real JavaScript in the editor to satisfy the mission win conditions.

### 2. The Multi-Sector JavaScript Curriculum
* **Sector 0: The Grand Showcase** — Observe how sequential JavaScript instructions control physical hardware.
* **Sector 1: Vector Ignition** — Learn `let`, `const`, numbers, and drone navigation methods (`drone.move()`, `drone.turnRight()`, `drone.turnLeft()`).
* **Sector 2: Laser Interlocks** — Learn conditionals (`if / else`) and optical sensor scans (`drone.scanAhead()`) to avoid active hazards.
* **Sector 3: Harvesting Loops** — Learn `for` and `while` loops to harvest energy conduits with zero repeated code.
* **Sector 4: Subroutine Protocols** — Learn functions and reusability (`function harvestAlcove()`) to clear branching chambers.
* **Sector 5: Radar Array Lock** — Learn array filtering (`drone.radar().filter(...)`) and target acquisition.

### 3. Integrated Bot Studios
* **🎨 DRAW BOT (Interactive Pixel Matrix)**:
  * 16x16 tactile drawing grid with vertical symmetry mode.
  * Live 60 FPS hologram preview rotation.
  * Install your hand-drawn robot directly onto your drone in the game arena!
* **💻 CODE A BOT (Learn JavaScript Graphics Programming)**:
  * **Lesson 1: Coordinates & Colors** — Learn 2D array coordinates `grid[row][col] = colors.CYAN`.
  * **Lesson 2: Armor & Treads with Loops** — Learn `for` loops to draw 10-pixel tank treads and armored hulls in just a few lines.
  * **Lesson 3: Angled Wings & Geometry** — Learn math and conditionals (`if`) to calculate swept stealth fighter wings.
  * Real-time in-studio compiler with error logs and live hologram testing.
  * Click **⚡ INSTALL ON ARENA DRONE** to fly the bot you programmed with JavaScript!

### 4. Virtual Hardware & Audio Synthesizer
* **HTML5 Canvas 60 FPS Engine**: High-contrast cyberpunk grid, smooth positional/angular interpolation, dynamic headlights/scanner cone, thruster particles, and energy core auras.
* **100% Procedural Web Audio API**: Zero external audio files to download. Procedural mechanical clicks, thruster hums, scan pings, crystal chimes, and victory fanfares.
* **Manual Remote Drive**: On-screen D-Pad and keyboard controls (`W`, `A`, `S`, `D` / Arrow keys, `Space` for scan, `H` for hack) for quick manual testing.
* **Infinite Loop Watchdog**: Protects the browser tab from accidental freezes when writing while/for loops.
* **Persistent Memory**: Progress and code changes are automatically saved to `localStorage`.
